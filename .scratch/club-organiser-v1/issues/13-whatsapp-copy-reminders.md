# 13: WhatsApp copy reminders

**What to build:** On any match, a captain or admin can copy a ready-to-paste WhatsApp message: a reminder naming who hasn't answered, or a share message with the match details and a link to the match.

**Blocked by:** 07

**Status:** claimed

- [ ] "Copy reminder" builds a message with the match (team, opponent, date, time) and the names of active members of the team who haven't answered, plus the match link
- [ ] "Copy share message" builds a message with the match details and its public calendar link
- [ ] Messages never contain personal links
- [ ] Messages are in Czech by default, with an option for English
- [ ] Building the message is a club core query covered by a test (with a fixed clock and fixed responses)
