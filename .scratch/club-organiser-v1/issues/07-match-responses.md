# 07: Match responses

**What to build:** From their personal link, a member answers yes, maybe or no for any match (their own team's or another team's), changes the answer at any time, and sees which matches they haven't answered yet.

**Blocked by:** 05

**Status:** claimed

- [ ] The club core has a "record response" command (member, match, yes, maybe or no); the latest answer wins
- [ ] Members can answer for matches of any team (so they can be substitutes)
- [ ] The "my upcoming events" view highlights unanswered matches
- [ ] The core can list, for a match, who said yes, maybe, no, or hasn't answered (active members only)
- [ ] Answering takes one tap on mobile; the buttons are large
- [ ] Playwright smoke test: open a personal link, answer a match, reload, the answer is still there
