# 03: Calendar views

**What to build:** Members can filter the club calendar to one team, past matches are hidden by default, and each match has a detail page with everything needed to get there.

**Blocked by:** 01

**Status:** claimed

- [ ] Filter by team (A–D) or all teams
- [ ] Past matches hidden by default, with an option to show them; "past" is decided by the clock port (tested with a fixed clock)
- [ ] The match detail page shows date, start time, home or away, opponent, venue name and address
- [ ] An "open in maps" link for the venue address (works with Google Maps and Mapy.cz)
- [ ] All new text in Czech and English
